I Matcher Prompt Template                                                                                                   773

The LLM matcher receives a ﬁxed system prompt and a stage-speciﬁc user prompt constructed as follows.                       774

System prompt.                                                                                                              775

     You are an expert document analyst specializing in user proﬁling. Given a document excerpt from a research report      776
     and a set of candidate user proﬁles, identify which user this document was most likely produced for. Focus on          777
     content priorities, framing, vocabulary, and topic angles that reﬂect the user’s background, goals, and preferences.   778
     Call submit_attribution with your answer.                                                                              779

User prompt structure.                                                                                                      780

  1. A stage-speciﬁc header (Research Planning Brief, Search Queries and Retrieved Sources, Compressed Re-                  781
     search Summaries, or Final Research Report (excerpt)) followed by the artifact text, truncated to the stage            782
     character limit (Planning 4,000; Search 3,500; Compression 6,000; Writing 8,000 with opening and tail pre-             783
     served).                                                                                                               784

  2. A Candidate User Proﬁles section listing each candidate as Candidate A / B / C with the full persona text.             785

  3. A closing instruction: “Which candidate proﬁle (A, B, or C) best matches the perspective, priorities, and              786
     content framing of the document above? Call submit_attribution.”                                                       787

   Candidate order is deterministically shufﬂed per run and stage using a SHA-256-derived seed, ensuring position           788
bias cannot produce a systematic accuracy advantage for any ﬁxed candidate slot. The matcher is called with                 789
temperature 0 and a structured submit_attribution tool that enforces a single-label response.                               790
