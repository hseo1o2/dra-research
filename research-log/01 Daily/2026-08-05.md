### 1. EXP-019 — Equal character-budget Solar rematch (seed 0)

- **목표:** LLM matcher에 입력되는 character budget이 stage마다 다른 점(Search 3,500 vs Write 8,000)이 dip-and-recovery 궤적의 주 원인인지 확인.
- **설계:** seed-0 60개 report, 전 stage를 동일 3,500자로 truncate한 뒤 Solar Pro 재매칭.
- **실행:**
  - `scripts/llm_matcher.py --equal-char-budget 3500 --output-dir runs/confirmatory/matches_equal_budget_3500_seed0`
  - `scripts/analyze_equal_budget.py` (paired analysis)
  - `scripts/candidate_protocol.py`에 `canonical_pilot_run_id` helper 추가.
  - `scripts/llm_matcher.py`에 `--equal-char-budget` 플래그 추가 (+109 lines, −34 lines).
- **결과 (n=60 seed-0, paired):**
  | Stage | Default | Equal 3,500 | Δ | 95% CI |
  |---|---:|---:|---:|---|
  | Planning | 0.800 | 0.800 | 0.000 | [0, 0] |
  | Search | 0.533 | 0.517 | −0.017 | [−0.050, 0] |
  | Compression | 0.567 | 0.600 | +0.033 | [−0.033, +0.100] |
  | Writing | 0.817 | 0.800 | −0.017 | [−0.067, +0.033] |
  - **Dip-and-recovery 보존**: Search < Plan, Write > Search (equal budget에서도 동일).
  - 모든 Δ의 CI가 0을 포함하거나 끝에서 접함 → budget confound 설명 불충분.
- **해석:** character-budget 차이는 Search dip의 충분 원인이 아님. BM25 / queries-only control과 일관성 유지.
- **비용:** Solar credit, 현금 0.
- **산출물:** `runs/confirmatory/matches_equal_budget_3500_seed0/`, `analysis_equal_budget_3500_seed0/summary.json`, `paper/analysis/equal_budget_control.md`.

### 8. EXP-020 — Mismatched-brief write-only ablation

- **목표:** brief를 제거(EXP-017)하는 것을 넘어, **잘못된 persona의 brief를 주입**했을 때 Writing Acc가 얼마나 떨어지는지 확인. Brief content의 interventional 역할을 분리.
- **설계:** EXP-017 wave 1과 동일한 15개 report (tasks 2,4,7,9,12, seed-0). Plan/Search/Compress 동결, Writing prompt의 `<Research Brief>`를 **donor persona**(cyclic next userid in `personas_n3`)의 brief로 교체. Findings + user messages는 GT 그대로.
- **실행:**
  - `scripts/write_only_nobrief.py` (other-brief mode)
  - Solar Write-stage matching; `ablation_otherbrief_` → `pilot_` candidate pair.
  - `runs/ablation/otherbrief_writeonly/analysis_paired.json` 분석.
- **결과 (n=15, 3-way 비교):**
  | 조건 | Write Acc@1 |
  |---|---:|
  | Full pipeline | **0.933** (14/15) |
  | No-brief (EXP-017 wave1) | **0.800** (12/15) |
  | Other-persona brief | **0.467** (7/15) |
  | Chance | 0.333 |

  | Contrast | Δ | 95% CI |
  |---|---:|---|
  | other − full | **−0.467** | **[−0.667, −0.200]** (CI 전체 0 미만) |
  | no-brief − full | −0.133 | [−0.267, 0.000] |
  | other − no-brief | −0.333 | [−0.600, 0.000] |

  - Paired full vs other: both✓ 7, full-only✓ **7**, other-only✓ 0, both✗ 1.
  - Donor가 예측된 경우: **1/15 (0.067)** — 틀린 brief가 GT 회복을 방해하지만 donor로 속이지도 않음.
- **해석:**
  1. 잘못된 brief를 주입하면 Writing GT 회복성이 **통계적으로 확실하게 감소** (CI 전체 0 미만).
  2. 효과 크기가 no-brief(−0.133)보다 **훨씬 큼**: brief 제거는 온화, **잘못된 brief 주입은 심각**.
  3. EXP-017 결과(no-brief residual Acc 0.80)와 합치면: brief content가 interventionally 중요하지만, residual signal도 있어 순수 tautology는 아님.
  4. n=15, seed-0 pilot; 방향과 magnitude가 명확해 추가 확장 불필요.
- **비용:** Gemini write-only 15 calls (매우 소액); Solar 15 calls (credit, 현금 0).
- **산출물:** `runs/ablation/otherbrief_writeonly/`, `analysis_paired.json`, `paper/analysis/otherbrief_writeonly.md`.
