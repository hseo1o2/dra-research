### 2. EXP-017 — Writing-only no-brief ablation

- **목표:** brief re-injection 없이도 Writing Acc@1이 유지되는지 확인 (W1 방어).
- **설계:** seed-0 확인용 30개 report, Plan/Search/Compress 동결, Writing prompt에서 `<Research Brief>` 제거 후 Gemini 재생성.
- **실행:**
  - Wave 1: n=15 pilot 실행.
  - Wave 2: `--resume`로 +15 추가 (총 n=30).
  - Solar Pro Writing-stage matching, `ablation_nobrief_` → `pilot_` candidate pair.
  - `scripts/analyze_nobrief_paired.py` paired analysis.
- **결과 (n=30 paired):**
  | 조건 | Write Acc@1 |
  |---|---:|
  | Full pipeline | 0.900 |
  | No-brief | **0.833** |
  | Δ | −0.067 |
  | 95% CI | [−0.167, +0.067] |
  - Paired 전환: both✓ 24, both✗ 2, full-only✓ 3, nobrief-only✓ 1.
  - Plan✓Search✗ 부분집합(n=8): full 7/8 → no-brief 6/8.
  - Wave별: wave1 Δ=−0.133, wave2 Δ=0.000; **풀 n=30 우선**.
- **해석:** re-injection이 일부 케이스를 돕지만 Writing Acc는 0.833로 chance(0.333)를 크게 상회. recovery는 순수 architectural tautology가 아님. CI가 0을 포함하므로 통계적 유의성은 주장하지 않음.
- **비용:** Gemini input 752,875 / output 234,589 = 987,464 tokens. 추정 ~$0.25–0.80.
- **산출물:** `runs/ablation/nobrief_writeonly/`, `analysis_paired.json`, `scripts/write_only_nobrief.py`, `scripts/analyze_nobrief_paired.py`.

### 3. EXP-018 — Attribution–utility GPT judge

- **목표:** stage Acc@1과 personalization utility score의 상관 측정 (W2 방어).
- **v1 실행:** GPT-4o-mini, temperature 0, 120 reports × 2 axes.
  - 결과: 두 축(content / presentation)이 **120개 전부** identical → dimension collapse.
  - Mean 4.508/4.508; Write✓-Write✗ Δ=+0.323, r=0.183.
  - **Ceiling effect** + collapse로 v1은 내부 증거로만 사용.
- **v2 실행 (authoritative):** rubric 개선 — 두 축의 독립 근거 강제, ceiling 억제.
  - Mean content 4.008 / presentation 3.650.
  - Frac identical axes 0.608 (v1 1.000에서 개선).
  - Write✓-Write✗ Δ=+0.099, r=0.151, task-bootstrap CI [−0.021, +0.225].
  - **결론:** attribution-utility 상관은 약하고 불안정함 (CI가 0 포함). Attribution = recoverability diagnostic, utility의 대체재 아님.
- **비용:** GPT 120 calls, input 535,967 tokens, output 14,012. 추정 ~$0.06–0.09.
- **산출물:** `runs/confirmatory/utility_judge_gpt4omini/` (v1), `utility_judge_gpt4omini_v2/utility_summary.json` (v2), `scripts/utility_personalization_judge.py`.

- No-brief Writing Acc@1 0.833: brief re-injection이 주 원인이 아님. 잔류 신호(findings, user messages)가 충분.
